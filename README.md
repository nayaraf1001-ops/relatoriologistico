# Sistema Web de Indicadores Operacionais — Penske | Mercedes-Benz

Plataforma web responsiva para registro diário de indicadores operacionais da **Penske Logistics** na operação **Mercedes-Benz**, com cálculos automáticos, validações de negócio, dashboard gráfico em tempo real, exportação em PDF/Excel e envio oficial por e-mail via servidor SMTP.
